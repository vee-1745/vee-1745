### 👨‍💻 About Me

I'm a Computer Science undergrad at **VIT-AP University**, specializing in **Data Analytics** with a strong pull toward **AI/ML** and **cybersecurity**. I like building things end-to-end — from training and explaining models to shipping small developer tools — and I spend a fair bit of time in CTFs, pulling apart apps and protocols to see how they break.

- 🔭 **Currently working on:** an Explainable AI (XAI) capstone project, extending SHAP/LIME coursework into a Grad-CAM-based explainability app
- 🛠️ **Recently built:** a VS Code extension powered by the Claude API — inline code generation, bug detection, and hover-based Explain/Fix actions
- 🌱 **Currently learning:** Backend Development, DSA, Cybersecurity, DevOps — with side curiosity in Aerospace Engineering & Advanced Physics
- 🏆 **Highlights:** NASA Space Apps Challenge participant (*AI Exoplanet Hunter*), reinforcement-learning hackathon on small-model reasoning
- 🚩 **CTF work:** Android app security analysis (static analysis, credential/URI-scheme issues), RSA cryptanalysis on weak key generation
- 💬 **Fun fact:** I can name the culprit before Conan does — anime marathons are my other debugger
